# 主开发者任务清单

你负责的是自动驾驶主干，不是仿真器安装或测试脚本。

## P0：先完成主干闭环

1. **状态机**：将当前按 scenario 直接映射的简化逻辑改为显式状态转移表，加入 `INIT → STANDBY → 功能态 → FINISHED/EMERGENCY`，实现传感器超时和恢复策略。
2. **定位**：在当前真值透传基础上加入 GNSS/IMU 噪声输入、EKF 或至少一阶滤波，并输出定位有效性和协方差。
3. **规划接口**：定义 `PlannerBackend`，保留传统规划和外部 ROS2 planner 两种实现，统一输出 `Trajectory`。
4. **控制器**：实现纵向 PID、横向 Pure Pursuit，加入速度/转角/加速度限幅和紧急停车优先级。
5. **ACC**：使用 Radar 目标实现前车选择、时距控制、前车消失后的巡航恢复。

## P1：完成四类功能

1. NOA：参考线跟踪、静态障碍物减速/绕行。
2. APA：停车位目标坐标、倒车轨迹和停车完成条件。
3. AVP：停车场 waypoint 路径跟踪和低速避障。
4. 所有功能加入成功、失败、超时和紧急停车条件。

## P2：加入可替换算法

1. 感知插件：传统真值/聚类实现作为 baseline。
2. Python 外部感知节点：先实现 mock detector，再接 ONNX Runtime CPU 模型。
3. Python 外部规划节点：输入感知和定位，输出统一 `Trajectory`。
4. 对比传统实现和外部实现的延迟、轨迹误差和成功率。

## 建议开发顺序

```text
状态机 → 控制器 → ACC → NOA → APA/AVP → 插件替换 → 指标调参
```

每完成一项，至少提供一个可复现命令和一个测试场景；不要修改 topic 名称而不更新 `docs/system_requirements.md`。
